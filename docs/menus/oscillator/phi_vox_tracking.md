# PhiVox Formant Tracking

Blends the PhiVox oscillator's formant frequencies from fixed Hz (0: vocal behavior — the voice's identity survives transposition, like a real vocal tract) to note-relative ratios (50: harmonic overtone behavior — the whole timbre transposes with pitch, like a conventional oscillator). Intermediate values give partial formant shift.

Available when oscillator type is set to PhiVox.
