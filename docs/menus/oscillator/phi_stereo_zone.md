# Phi Stereo Zone

Zone-style stereo control shared by the phi-family oscillators. Position within each of the eight zones sets the stereo AMOUNT (every zone starts mono, so the knob's origin is always mono); the zone selects the stereo CHARACTER, interpreted per oscillator - PhiWeave/PhiGendy: dual scan taps (two pickup positions; zones vary tap distance, tonal tilt, counter-scanning), PhiSwarm: slave separation, PhiVox: formant separation. Zones: Slim, Near, Open, Tilt, Wide, Sway, Split, Vast.

Available when oscillator type is a phi-family oscillator.
